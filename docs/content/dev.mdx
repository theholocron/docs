## PackageHeader

Renders the package name, links, and optional description. The `sandboxUrl` field on the entry adds a Sandbox link.

<PackageHeader entry={client} description="TypeScript client for the GitHub REST API." />

---

<PackageHeader entry={clientWithSandbox} description="With sandboxUrl set on the entry." />

---

## PluginHeader

Same as `PackageHeader` with a capability badge appended.

<PluginHeader
  entry={plugin}
  capability="observability"
  description="Sentry error tracking and performance monitoring."
/>

---

<PluginHeader entry={plugin} capability="observability" />

---

## Installation

Renders a `pnpm add` block. Supports `dev` and `global` variants.

<Installation package="@theholocron/github-client" />

<Installation package="@theholocron/eslint-config" dev />

<Installation package="@theholocron/cli" global />

## CapabilitiesTable

Two-column table of capability / token pairs for plugin pages.

<CapabilitiesTable
  rows={[
    { capability: "observability", token: "HOLOCRON_SENTRY_TOKEN (sentry)" },
    { capability: "error-tracking", token: "SENTRY_DSN" },
    { capability: "performance", token: "SENTRY_TRACES_SAMPLE_RATE" },
  ]}
/>

## PackageGrid

Package table from a `LinksRegistry`. Shows "Package" header by default, "Plugin" when `type="plugins"`.

<PackageGrid packages={getClients()} />

---

<PackageGrid packages={getPlugins()} type="plugins" />

## RelatedProjects

Picks a random cross-registry selection; refreshes on each build. `count` defaults to 3.

<RelatedProjects current="github-client" />

---

<RelatedProjects current="holocron-plugin-sentry" count={5} />

## Sandbox

Embeds an interactive Sandpack sandbox. Runs client-side only via `client:only="react"`.

<Sandbox
  template="vanilla-ts"
  files={{
    "/index.ts": `import { createGitHubClient } from "@theholocron/github-client";\n\nconst client = createGitHubClient({ token: process.env.GITHUB_TOKEN });\nconsole.log(client);`,
  }}
  dependencies={{ "@theholocron/github-client": "latest" }}
/>

---

<Sandbox
  template="react-ts"
  files={{
    "/App.tsx": `export default function App() {\n  return <h1>Hello from Sandpack</h1>;\n}`,
  }}
  height={300}
/>
